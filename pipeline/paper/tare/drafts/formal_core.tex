\section{Problem Model}
\label{sec:model}

\paragraph{Program and release.}
A black-box program $P$ maps records $R$, reference $E$, and options $o$ to a
tabular body (headers ignored). $E$ is an ordered list of entries; each has a
strict hash $h(e)$ (\texttt{entry\_content\_hash}): SHA-256 of the entry after
dropping caller-declared volatile tags. A release $E\!\to\!E'$ yields stable
entries $S=\{e\in E':h(e)\in h(E)\}$, changed $\Delta=E'\setminus S$, removed
$h(E)\setminus h(E')$, and changed fraction $f_\Delta=|\Delta|/|E'|$
(\texttt{changed\_fraction}).
% source: MEASURED pipeline/results/reference_kill_r1.json unchanged_strict=26082 z_new=30134; DERIVED identical_pct=100*unchanged_strict/z_new
Every output row is attributable to one pair $(r,e)$ with printable fields
$f(r,e,o,g(E'))$, where $g(E')$ is a reference-wide statistic vector (entry
count, total length, \ldots). Exact re-annotation returns
$\mathrm{body}(P(R,E',o))$ byte for byte, or refuses and returns that full run.

\paragraph{Coupling taxonomy.}
\begin{itemize}
\item \textbf{C0 (entry-local):} $f$ independent of $g$ and of every $e'\neq e$.
  Example: Infernal under Rfam's recommended command. Action: replay
  (\texttt{\_run\_exact}).
\item \textbf{C1 (reference-size):} $f$ depends on $E'$ only through a normalizer
  in $g$ that $P$ exposes or \sys rescales
  (\texttt{reference\_fit.MEMBERS}). Example: HMMER with \texttt{-Z}. Action:
  pin (\texttt{pin\_tokens}, \texttt{\_pinned}) or refuse if uncovered
  (\texttt{uncovered\_members}).
\item \textbf{C2 (neighbor/order):} the line for $(r,e)$ depends on neighbors of
  $e$ or on input order. Example: DIAMOND's boundary filter. Action: refuse.
\item \textbf{C3 (cross-record global):} depends on other records (e.g.\
  target--decoy FDR). Action: refuse when observed.
\item \textbf{C4 (nondeterministic):} fixed $(R,E',o)$ disagrees across runs.
  Action: refuse when observed.
\end{itemize}
Refusal rules: \textbf{R1} no contract
(\texttt{probe\_fit}/\texttt{fit\_observations}); \textbf{R2} size-dependent, no
pin; \textbf{R3} in-situ pin check fails (\texttt{\_pin\_check}); \textbf{R4}
non-candidate pair in replay; \textbf{R5} pad changes a line (\texttt{\_ic2});
\textbf{R6} audit differs (\texttt{bounded\_audit\_size}). C0/C1 use replay; C2--C4
refuse (R1--R3 on the probe, R4--R6 on the update). Side-file rewrites and
invalidate-groups (\texttt{apply\_aux\_filter}, \texttt{invalidated\_hashes}) are
declarations that keep C1 sound, not a sixth class.

\paragraph{Exactness (C0/C1).}
\begin{assumption}[Determinism]\label{asm:det}
Fixed $(r,e,o,g)$ prints the same cells every time.
\end{assumption}
\begin{assumption}[Pin fixes $g$]\label{asm:pin}
Pinned options set every fitted size member of $g(E')$ to the full-release
value (\texttt{pin\_values}; identity if none fit).
\end{assumption}
\begin{assumption}[Unique attribution]\label{asm:key}
After key widening, each body row has a unique $(r,e)$ (\texttt{row\_key}).
\end{assumption}
\begin{assumption}[Row-determined body]\label{asm:order}
The body is a deterministic function of its rows in fixed record order
(\texttt{\_batched\_replay}).
\end{assumption}

\begin{proposition}[Exact merge]\label{prop:exact}
Assume C0 or C1 and~\ref{asm:det}--\ref{asm:order}. Let $C_r$ be $r$'s
candidates (cached stable hits plus discovery on $\Delta$;
\texttt{replay\_plan}). Running $P$ on each $r$ against $C_r$ with $g$ pinned,
then merging in record order, yields $\mathrm{body}(P(R,E',o))$.
\end{proposition}
\begin{proof}
Under C0/C1 and~\ref{asm:pin}, cells for $(r,e)$ equal $f(r,e,o,g(E'))$ on any
universe containing $e$. Discovery puts every new/changed hit in $C_r$; stable
hits remain cached. By~\ref{asm:key}--\ref{asm:order}, assembling those rows
reproduces the full body;~\ref{asm:det} removes drift.
\end{proof}
The probe tests factorization and the closed normalizer family (R1);
\texttt{\_pin\_check} tests~\ref{asm:pin} (R3); pads try to falsify C0/C1 toward
C2 (R5); a non-candidate emission falsifies completeness of $C_r$ (R4). These
are tests, not a proof of C0/C1 on the full input.

\paragraph{Not covered.}
C2: omitting a neighbor can change a line despite a pin; refuse (neighbor pad;
R5). C3: per-record candidates are incomplete; refuse when seen. C4:
\ref{asm:det} fails; refuse. Residual risk: couplings below fraction $\kappa$,
or that evade pads and the audit sample, are checked only by sampling. Project
limitation F6 (coupling outside the closed family that still looks locally
consistent) is not a shipped guarantee.

\paragraph{Audit bound.}
If at least a fraction $\kappa$ of records would differ under a wrong update,
a with-replacement sample of size $s$ misses all of them with probability
$\le(1-\kappa)^s$. Setting that $\le\varepsilon$ gives
\begin{equation}
s=\bigl\lceil\ln\varepsilon/\ln(1-\kappa)\bigr\rceil.
\label{eq:audit-s}
\end{equation}
% source: MEASURED pipeline/docs/EXACT_REPLAY_PROTOCOL.md; TEXT s=299; NOMINAL eps=0.05; NOMINAL kappa=0.01
For $\varepsilon=0.05$, $\kappa=0.01$, $s=299$ (\texttt{bounded\_audit\_size};
default in \texttt{\_\_main\_\_.py}). This bounds the chance of \emph{shipping} a
wrong update given $\ge\kappa$ affected (R6); it does not bound couplings below
$\kappa$. Empirically, 3 of 400 adversarial trials at $\ge 1\%$ affected
shipped under the bounded audit.
% source: MEASURED pipeline/results/adversarial/v2_summary.json arms.bounded.covered_unsafe=3 arms.bounded.covered_trials=400

\paragraph{Cost model.}
With stock time $T_{\mathrm{stock}}$,
\begin{equation}
T_{\sys}\approx a\,f_\Delta\,T_{\mathrm{stock}}+c\,T_{\mathrm{stock}},
\label{eq:cost}
\end{equation}
where $a$ scales selection and $c$ collects replay, check, audit, and parsing.
Fallback when $f_\Delta>(1-c)/a$ (\texttt{break\_even\_f}); default threshold
$0.80$ with no timing history.
% source: MEASURED pipeline/results/breakeven/measured.json threshold_default=0.8; NOMINAL one=1

\paragraph{Why this generalizes.}
Any program whose rows factor as $f(r,e,o,g(E))$ fits the model; C2--C4 remain
refuse classes. Cross-field evidence is catalogued in
\texttt{pipeline/docs/NONBIO\_LITERATURE.md} on \texttt{hub/collect-w8-w5x}; the
hub chooses citations.
