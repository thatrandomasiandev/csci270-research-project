# Paper

There is one paper: **`tare/`** — *Pin and Replay, or Refuse: Exact Incremental Re-annotation Across
Reference Database Releases* (TARE).

- Source: `tare/main.tex`, `tare/refs.bib`; figures are generated by `tare/figures/make_*.py` from committed
  files under `pipeline/results/`.
- Every number carries a `% source:` comment. Check them with `python3 pipeline/artifact/check_paper_sources.py`
  (must print `mismatches=0`).
- Build: `cd pipeline/paper/tare && latexmk -pdf main.tex`.
- Only the hub session edits `tare/main.tex`. Experiment agents commit results and put proposed paper sentences, with
  their source keys, in their final report. See AGENTS.md, "Paper ownership".

Older material is archived, not live: `archive/paper-v1-reference-side/` (the first paper, rejected in review),
`archive/paper-clam-draft/` (an early TARE draft), and `archive/stale-paper-edits/` (uncommitted edits saved as patches
on 2026-10-19 when duplicate paper copies were removed).
