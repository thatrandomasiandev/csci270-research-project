## Deviations

- First-use is implemented and unit-tested. The grid sets `first_use_k = 0`. Every trial has a fresh cache, so leaving it on would make every trial a full comparison.
- The non-exact incremental path still audits only when `reused > 0`. That path's full run is the tool itself, not a candidate-subset replay.
- The pilot ran on a dirty tree at `1c65571`. The measured grid and `confirm_v2.json` ran clean at `bcca3b4`.
- Sizing uses the binomial formula. Hypergeometric and shim probabilities are reported beside it. They are not the sizing rule.
- `k` in {1, 5} is below `k_min/n = 0.01`. Those misses are inside the stated guarantee.
- Server fractions scale existing `verify_s`. They assume the audit's time grows with the number of audited records. No new exclusive timing job.
- Table 3 reruns do not enter the new audit. Disclosed per file as `audit_reached: false`.
- Seed `20261239` is unused. Seeds `20261231`–`20261238` are the pilot, the grid, and the confirmation.
