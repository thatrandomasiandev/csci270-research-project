## The definition, unchanged

The paper's model is

```text
T_TARE = a * f * T_stock + c * T_stock
S      = 1 / (a * f + c)
```

`a` is how discovery scales with the changed fraction. `c` is every other cost as a fraction of a stock run. The laptop figure already reduces one observation per proteome by

```text
a_g = discovery_s / (f * stock_wall_s)
c_g = (tare_wall_s - discovery_s) / stock_wall_s
```

and takes the arithmetic mean (`sum/n`). Published rounding of that laptop fit is `a = 1.06`, `c = 0.152`.

The server fit uses the same ratios. Each of the nine genomes has three alternating repeats. B repeat `r` is paired with A repeat `r`. `U` is that B repeat's `wall_s`, not `phases.total_s`.

```text
a_{g,r} = discovery_s / (f * A.wall_s)
c_{g,r} = (B.wall_s - discovery_s) / A.wall_s
a_g     = (a_{g,1} + a_{g,2} + a_{g,3}) / 3
c_g     = (c_{g,1} + c_{g,2} + c_{g,3}) / 3
a       = sum of a_g / 9
c       = sum of c_g / 9
```

`f` is Pfam 38.1→38.2, `pairs.json` `f_delta` = 4052/30134 = 0.13446605163602576. Every included genome has three pairs, so the mean of the nine `a_g` equals the mean of all 27 ratios. Same for `c`. Medians are not inputs to `a` or `c`. `S_g` is still median stock wall over median TARE wall, and it is only used to choose which genomes the phase figure draws.
