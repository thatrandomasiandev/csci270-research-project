# Probe miss-rate evaluation (pre-registered)

Written **2026-09-27, before** any `fixtures/probe_eval/` tool or
`results/probe_eval.json`. Do not edit this file after seeing those
results. Local only. No CARC. Do not touch `jobs/`,
`results/savings_*`, or `docs/SAVINGS_PROTOCOL.md`.

The paper’s correctness claim is: probes (determinism, shuffle,
subset-invariance, field-role perturbation, late keys) plus MATCH
(and the optional audit) keep an unsafe cache from shipping. This
protocol **measures** how often that fails. It is not a new method.

Closest prior art we are **not** claiming: Dune
`cache-check-probability` (rule-level re-exec), vCache (LLM semantic
δ), mutation testing of memo stores. Those are command- or
model-layer. This is record-layer probe miss rate on synthetic
faults.

```
python3 -m acts run --kind {vcf,fasta} --probe-n N --cache C --input X -- <tool>
```

Three files, fixed seeds (**20260927**):

| File | Role |
|------|------|
| input 1 | Infer + populate (`probe_n` = first *N* records) |
| input 2 | Reuse. Must SHIP and MATCH vs a full run of input 2 |
| input 3 | Held-out replay of the cache vs a **fresh stock** run. Not a fourth infer |

`N_rec` = **2500** records per file (so `probe_n` ∈ {50, 200, 500, 2000}
is a prefix of input 1). Input 2 has the same length as input 1
(overlap + new records). Input 3 is a cached-key subset, possibly
with a class-specific twist (below).

---

## Fault classes

Each class is a small Python tool, **both** `--kind vcf` and
`--kind fasta`. Four frequencies *p* ∈ {1, 0.1, 0.01, 0.001}: a
record is **live** iff
`hash(seed, class, format, i) mod 10000 < 10000 p`.
Dead records are safe per-record maps (key → produced field).

| ID | Fault | VCF produced field | FASTA produced field |
|----|-------|--------------------|----------------------|
| F1 | Nondeterministic value on live records (`secrets.randbelow`) | `INFO/ANN` | score column |
| F2 | Live record copies the **previous** record’s key | `INFO/ANN` includes prev POS / name | score includes prev name |
| F3 | Live record writes the **file record count** *N* | `INFO/ANN=N` | score = *N* |
| F4 | Live record depends on ID (VCF) or description (FASTA) | `INFO/ANN` includes ID | score includes desc |
| F5 | Rare extra produced field, only on live records, depends on ID/desc | `INFO/RARE=<id>` | extra column = desc |
| F6 | Reads `ACTS_PROBE_EVAL_ENV` (not in argv) on every record | `INFO/ANN` includes env | score includes env |
| F7 | Live record writes `time.time_ns()` | `INFO/ANN` | score |
| F8 | Live record’s **group order** (two produced rows / two ANN tokens) depends on the previous record | token order in `ANN` | two table rows swapped |

F6 ignores *p* (always on). Frequency variants are still generated so
the table is rectangular; they are the same tool.

### Controls (must SHIP)

Five safe tools, no live-fault logic:

| Control | Format | What it does |
|---------|--------|----------------|
| C1 | vcf | `ANN` from CHROM:POS:REF>ALT only |
| C2 | vcf | C1 + FILTER rewritten to `PASS` (PRODUCED) |
| C3 | vcf | C1 + QUAL pass-through |
| C4 | fasta | one score row from the sequence; name pass-through |
| C5 | fasta | C4, but sequences hashing to 0 emit **no** rows (`EMPTY`) |

## Expected catch (locked before the run)

A probe **catches** a (class, *p*, format, `probe_n`) cell if input 1
returns that refuse. MATCH on input 1 or 2 is a **later gate**, not a
probe. Pre-registered probe (not MATCH) expectations:

| ID | Probe that should fire, **if a live record is in the probe prefix** | If no live record in the prefix |
|----|---------------------------------------------------------------------|----------------------------------|
| F1 | **(a) determinism** → `REFUSE_NONDETERMINISTIC` | probes pass; MATCH on input 1 fails if any live record is in the file (miss-run ≠ full-run) |
| F2 | **(b) shuffle** and **(b2) subset** → `REFUSE_NEIGHBORS` or `REFUSE_GLOBAL` | probes pass; MATCH on input 2 may fail when a live hit sits next to a different neighbor |
| F3 | **(b2) subset** → `REFUSE_GLOBAL` (singleton *N*=1 ≠ probe *N*). Shuffle **passes** (every live record writes the same *N*) | probes pass; input 2 MATCH **passes** (same *N*); input 3 uses a **different length** → stock ≠ replay |
| F4 | **(c) perturbation** → widen ID/desc, then SHIP; or `REFUSE_AMBIGUOUS` if still depends | probes pass without widen; input 2 uses **same** IDs/descs (MATCH passes); input 3 **changes** ID/desc on cached keys |
| F5 | late-key probe on first miss-batch that carries `RARE` / extra col; then (c) on that subset. If the rare field is in the probe prefix, (c) fires on input 1 | if never seen in probe or first 200 late carriers: uncached key; replay may drop it → MATCH or input-3 mismatch |
| F6 | **undetectable by design** (argv-named inputs only; `CACHE_KEY_PROTOCOL.md`) | all probes + MATCH pass while env is held fixed; input 3 sets a **different** env |
| F7 | **(a) determinism** → `REFUSE_NONDETERMINISTIC` | same as F1 (MATCH on any file with a live record) |
| F8 | **(b) shuffle** and/or **(b2)** → `REFUSE_NEIGHBORS` / `REFUSE_GLOBAL` | probes pass; MATCH may fail on a new neighbor |

Controls: every `probe_n` → **SHIP** on input 1 and 2; input 3 replay
**equals** stock. Any refuse is a **false refuse**.

F6 is **outside the method’s guarantee**. Report it as a limitation,
not as a probe bug.

---

## Metrics (locked)

- **unsafe-ship** = unsafe (class, *p*, format, `probe_n`) that
  (1) SHIPs input 1, (2) SHIPs and MATCHes input 2, (3) input-3
  replay ≠ fresh stock. Denominator = all unsafe cells (8 × 4 × 2 × 4
  = 256). F6’s four frequencies count as four cells (same tool).
- **catch rate per probe**: among unsafe cells that refused on
  input 1, fraction whose first refuse is that probe’s decision.
- **catch rate per frequency**: among unsafe cells at that *p*
  (excluding F6), fraction refused on input 1 by any probe.
- **false-refuse rate**: controls that are not SHIP on input 1 or 2,
  over 5 × 4 `probe_n` = 20 cells.
- **smallest *p* reliably caught** at a `probe_n`: smallest *p* such
  that **both** formats of F1–F5, F7, F8 (not F6) refuse on input 1
  at that *p*. If none, write “none”.

`probe_n` ∈ {50, 200, 500, 2000}.

|-------|---------|

| F4, F5 | first 200 keys of input 1, **new** IDs / descriptions |
| F6 | first 200 of input 1, `ACTS_PROBE_EVAL_ENV=heldout` (populate used `base`) |

### PROJECTED, before any cell

Assumptions: a frequency-*p* fault is present independently on each
record; the probe is 8 records; the population correction is ignored.
This is the paper’s formula \(\Pr[\text{probe misses}] = (1-p)^n\), at
\(n = 8\). The seed realizes one draw. These probabilities are not a
target numerator.

| *p* | \((1-p)^8\) |
|-----|-------------|
| 1 | 0 |
| 0.1 | 0.43046721 |
| 0.01 | 0.92274469 |
| 0.001 | 0.99202794 |

At *p* = 0.01 the probe is empty of the fault with probability
**0.9227**. At *p* = 1 it cannot be empty.

What an empty probe implies, from the locked expected-catch table:

| Class | Full column | Audit column |
|-------|-------------|--------------|
| F1, F7 | **Not** unsafe-ship. MATCH fails on input 1 if the file has any live record. \((1-p)^{2500}\) is ~0 at *p* ≥ 0.01 and 0.082 at *p* = 0.001; a file with no live record is also clean on input 3, so replay equals stock | Unsafe-ship if the checked hits include no live record. Illustration, not a second metric: a floor-20 check misses an independent rate-*p* fault with probability about \((1-p)^{20}\) (0.8179 at *p* = 0.01). The locked audit escape for a fault that touches *h* hits remains \((1-q)^h\), *q* = 0.02 |
| F3 | Unsafe-ship when input 3 (first 100 records) is live. \(1-(1-p)^{100}\) is 0.6340 at *p* = 0.01 and 0.0952 at *p* = 0.001. Input 2 MATCH passes (same *N*) | The audit file has a different *N*, so a live checked hit is `REFUSE_AUDIT`. Otherwise unsafe-ship |
| F4 | **Unsafe-ship.** Input 2 keeps IDs/descriptions, so MATCH passes; input 3 changes them | **Unsafe-ship.** The audit sees the same IDs/descriptions |
| F2, F5, F8 | Same probe-miss probability. Unsafe-ship is neighbor- or rare-field-dependent. **Not** predicted as a determined miss | same |
| F6-env, F6-file | 8/8 unsafe-ship on this Mac (always on; no `strace`). Outside the 56. This is the locked limitation, not \((1-p)^8\) | same |
